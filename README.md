# Sovereign OS Project

The **Sovereign OS Project** is an independent research initiative founded by Robert Potter. It publishes the **Context Inversion Protocol** (a proposed edge-first profile) and **Sovereign OS Control Plane 1.6.0**, a public MIT-licensed local custody and provenance prototype.

## Entity Map

- **Context Inversion Protocol (CIP):** An edge-first implementation profile authored by Robert Potter. Authority would stay at the local edge; models would be replaceable utilities behind a gate. CIP is proposed, not shipped.
- **Sovereign OS (SOS):** Published MIT-licensed local control plane (version 1.6.0) for source custody, deterministic evidence, and operator-accepted knowledge. It is not CIP, not HCP, and it does not presently expose MCP.
- **Human Context Protocol (HCP) and Model Context Protocol (MCP):** Existing protocol families CIP may later use for scoped disclosure and tool transport. SOS does not implement them.
- **sovereignos.foundation:** The initiative's canonical web address. Its top-level domain does not specify the project's legal form or nonprofit status.

## Publication Status

This repository is the compiled deployment and distribution point for the project website and whitepaper. The website source and build pipeline are maintained privately. The SOS control plane is separately published under MIT. The CIP mediation layer remains a proposed runtime rather than shipped software.
