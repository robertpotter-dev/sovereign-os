# Sovereign OS Project

The **Sovereign OS Project** is an independent research initiative founded by Robert Potter. It publishes the **Context Inversion Protocol** and develops **Sovereign OS**, the protocol's proposed open-source reference implementation.

## Entity Map

- **Context Inversion Protocol:** An edge-first implementation profile authored by Robert Potter.
- **Sovereign OS:** The proposed open-source, agentic, locally-graphed reference implementation.
- **sovereignos.foundation:** The initiative's canonical web address. Its top-level domain does not specify the project's legal form or nonprofit status.

## Publication Status

This repository is the compiled deployment and distribution point for the project website and whitepaper. The website source and build pipeline are maintained privately. Until a permissively licensed implementation is publicly released, Sovereign OS is a proposed reference implementation rather than shipped open-source software.
