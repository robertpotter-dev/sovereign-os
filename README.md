# Sovereign OS

**Sovereign OS** is an open-source, agentic, locally-graphed prototype of the Human Context Protocol.

This repository serves as the public deployment and distribution point for the Sovereign OS website.

## Read the Whitepaper

You can read the full prologue and whitepaper live at:
**[https://sovereignos.foundation/](https://sovereignos.foundation/)**

## About

Sovereign OS declares that the local edge machine is not a terminal connecting to a corporate brain; it is the primary, sovereign data center of your life. By anchoring a temporally decaying memory graph completely on the edge via the Context Inversion Protocol, we ensure that the engine of intelligence serves the individual, structurally guaranteeing that the bicycle for the mind is never locked inside someone else's server farm.
